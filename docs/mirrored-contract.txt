# Statements the grounding contract shares with the files that mirror it.
# `docs/grounding-and-verification.md` is the master; the skills restate its
# rules at the point each one needs them, and `tests/test_docs_integrity.py`
# fails when a declared statement has left either end.
#
# The obligation runs one way, and that is the whole reason this file exists.
# An agent reads the skill it was invoked with and may never open the master, so
# a skill still carrying a superseded rule is the rule that gets applied - which
# makes a drifted copy worse than one that never mentioned the contract, because
# it reads as authoritative. `CLAUDE.md` states that obligation and the master
# lists where it is mirrored; neither could fail when a copy drifted.
#
# What is checked is a three-way agreement: every statement below must still be
# in the master's own prose AND in the file that mirrors it. The first half is
# the half nothing else had. A list of sentences held only against the skills
# goes stale the moment the master is reworded - it keeps passing, over a rule
# the master no longer states - and then the gate is agreeing with the copies
# about an original nobody read. Editing a rule in the master now fails here
# until the statement and every mirror move in the same change.
#
# Blockquoted lines in the master are excluded when its own prose is read,
# because a blockquote there is where the master says where it is mirrored, not
# where it states a rule. Without that exclusion a statement could be satisfied
# by the mirror list quoting it, and the check would be comparing the master's
# table with itself.
#
# One entry per line, `path :: statement`, the path relative to the repository
# root and the statement a substring of the collapsed text at both ends.
# Whitespace runs are collapsed first, so a statement matches across a wrapped
# line break. Blank lines and `#` comments are ignored.
#
# Keep each statement to the shortest fragment that could not survive its rule
# being dropped or reversed, so wording either side of it stays free to change.
# A path the master lists as a mirror with no statement declared here is a
# failure with instructions rather than a silent skip: otherwise the master's
# list could grow while what is checked stood still.
#
# Two things this file does not do. It does not check that a mirror states its
# rule in terms an agent can act on - `tests/test_grounding_contract_mirrors.py`
# and `tests/test_authority_order_mirrors.py` pin each skill's own operative
# wording, which is deliberately shorter than the master's. And a statement
# here is a shared phrase rather than the rule in full; the rule is the
# master's, and the reasoning behind it stays there.
